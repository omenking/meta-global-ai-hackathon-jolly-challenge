Jolly Tools

Local tools for the Chip's Challenge clone. Everything runs from this one server.

Tools

  • Project Manager
    Feature and task board for the game engine: list, kanban, comments, and feature review.
  • Asset Design Tool
    Iterate on generated tile art: versions, lottery runs, sessions, and judging.
  • Level Preview
    Render a level layout (rows plus legend) with its sprites. Add ?level=chip1 to pick a level.

Game

  • Game shell — not built yet
    The playable game is the game-shell feature on the board. Until it lands, use Level Preview above to look at levels.
