Tile Gallery — all 269 tile assets in the game

Every PNG under level-sprites/ and packs/*/assets/, drawn the way the game draws them: 512px sources scaled to the 64px world tile, each sprite composited over the floor_default base tile. Seamless board · Self-tiling check · Catalogue by pack

Seamless board — every tile edge to edge

All 269 tiles at 64px with zero gaps on the game's #111 board background, in catalogue order. This is the line-up check: edges, scale and footing sit exactly as they do in a level. Hover a tile for its file path.

Self-tiling check — full-bleed tiles against themselves

Each of the 258 full-bleed tiles repeated 3×3. Seams, banding or a pattern that does not wrap show up here; a tile that lines up with itself reads as one continuous surface.

Catalogue by pack

Same 64px rendering, grouped by where the file lives. “Full-bleed” tiles are opaque to their corners; “sprite” tiles have transparency and are shown over the floor base, as in game. Click a tile to open the native 512px file.
