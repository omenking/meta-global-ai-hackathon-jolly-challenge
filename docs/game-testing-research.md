What did learn when playing these games?

## Logical Technical Challenge vs "Fun"

### Sokoban
Sokoban is fun for a type of player that likes punishingly hard logical challenges. You run into deadends frequently and have to restart. The game maps are very small, so restarting is not tedious but you really have to think deeply about the challenge.

Sokoban the goal is simply to get the boxes onto very specific spots. The game can make you want to quit when you feel mentality exhausted.

### Chip's Challenge
Chips Challenge has logical challenges not as difficult as Sokoban, it introduces novel mechanics and time-limit, to feel like complex challenges. So the player feels rewarded for the perceived complexity and keep playing due to new emerging mechanics.

The goal is to collect all chips which unlock a final gate to the next level.

However the game can be tedious if you die late or end up deadlock and replaying the level may want to make you quit.

### Takeaway

- We don't want the game to mentally exhaust the player.
- We don't want hte game to feel tedious to replay a level when facing a deadend.
- We want the game to feel fresh and novel as you progress.
- We want to tell a story, and end goal.
