# Game Lore and Game Mechanics

## Game Lore
The game should revolve around Meta's Jolly character.
The orb should be Jolly's primary resource
We should expan the Jollyverse to have an antongist
We want the game mechanics to tell a story and provide ongoing theme.

## Base-level Game Mehanics

- Levels are an enclosed area.
- The level themselves are tiles
- We use tile-base movement
- Get to the elevator is the goal
- The elevator always is gated
- You must collect all the orbs to unlock the gate.
- There are coloured keys you can pick up
  - a coloured is consumed and will dissolve a colour lock block.
- You have eight slots for items held
- There is a timer that counts down
- There is a Orbs Left that counts down to let you know how many you need to unlock the gate.
- There can be floor squares taht explain the mechanics.
